# Foundation audit and local imports

Audit saving, download integrity, database replacement, image conversion and viewer
lifecycle. Repair evidenced failures with regression tests instead of replacing the
working native Qt architecture. Retain personal configuration and existing Library.

Import selected files/folders or dropped images on a worker, using streaming hashes,
bounded previews and recoverable metadata. Reference originals by default; optional
managed copies never remove originals. Exact duplicates share one catalog record.
Local pictures remain viewable and rateable without a website. Collection preferences
remain independent. Schema upgrades back up the old catalog before changing it.

Source recovery uses recorded URLs and exact MD5 queries through configured sources.
Filename hashes are evidence, not verified identities. Visual hashes offer candidates
for explicit review; they do not establish source identity. Source linking merges
catalog records transactionally while preserving notes, covers and preferences.
No image is uploaded or cloud provider invoked by importing or matching.

Verify core failure paths, importer fixtures, migration/reopen/merge, asynchronous
GUI import, offline viewing/actions, and rendered Windows UI. Build all existing test
groups and package with the current profile backed up before deployment. The initial
milestone was local; the later Woo Edit release follows the current release gates.
Recommendations and semantic AI search remain separate milestones.
